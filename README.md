# Interactive Smart E-Commerce System

A simple terminal-based E-Commerce system built using Python OOP concepts.

## Features
- View products
- Add products to cart
- View cart
- Checkout with discounts
- Error handling

## OOP Concepts Used
- Abstract Class
- Inheritance
- Encapsulation
- Polymorphism
